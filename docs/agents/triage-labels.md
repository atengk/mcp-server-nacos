# 问题分诊标签对照表 (Triage Labels)

智能体技能体系使用 5 种核心分诊角色划分任务状态。本文件定义这些角色在当前 GitHub 仓库中的实际标签字符与业务含义：

| 技能标准角色 | 当前仓库标签字符 | 业务含义与适用场景 |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | 待分诊：新提交的问题，需要维护者或智能体进一步评估与定级 |
| `needs-info` | `needs-info` | 待补充信息：等待问题提报者提供复现步骤、日志或环境说明 |
| `ready-for-agent` | `ready-for-agent` | 智能体可执行：需求或 Bug 定义完备，上下文充足，允许后台智能体离线全自主实现 |
| `ready-for-human` | `ready-for-human` | 需人工介入：涉及架构重大决策、关键外部凭据或需人类开发者主导实现的任务 |
| `wontfix` | `wontfix` | 不予处理：重复提报、超出项目范围或设计所限不予采纳的议题 |

当技能提及特定分诊角色（如“应用适合智能体执行的标签”）时，统一使用上表对应的标签字符。
